# Font notices

pick up bundles unmodified Google Fonts distributions of Anton, DM Mono, DM Sans, and Fraunces. These files are served locally; the app makes no runtime requests to a font service.

- Anton: `anton.ttf`, license `anton-OFL.txt`
- DM Mono: `dm-mono.ttf`, license `dmmono-OFL.txt`
- DM Sans: `dm-sans.ttf` and `dm-sans-medium.ttf`, license `dmsans-OFL.txt`
- Fraunces: `fraunces.ttf`, license `fraunces-OFL.txt`
